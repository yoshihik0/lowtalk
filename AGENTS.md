# LOWTALK agent instructions

When the user asks to deploy, publish, update to the latest version, configure an administrator, recover access, or reset the administrator password, read `skills/lowtalk-operator/SKILL.md` and follow it.

Never ask the user to paste their permanent administrator password into chat. Never write credentials to tracked or ignored project files. The only password an agent may display is the short-lived, forced-change temporary password produced by the repository script.
